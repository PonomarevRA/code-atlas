# Проверяемое сравнение class и folder группировки

`fixtures/*.json` — неизменяемые входные факты с явным происхождением. Корпус
включает направленный hub, SCC, disconnected/isolate, плотные группы со слабой
связью и маленький импортный граф реальных файлов Atlas. Последний получен
статическим чтением AST импортов: это не полный call graph, coverage partial.
Файлы исходного проекта не исполняются. Fixtures не являются ground truth
функциональных границ.

Запуск из корня проекта:

```sh
.venv/bin/python tools/performance/module-analysis/run.py --repeats 3 --output outputs/module-analysis/report.json
```

Отчёт содержит hashes входов, идентичности проекций, seed, версии, partitions,
направленную Q по исходным наблюдаемым счётчикам, timings и peak Python
allocations. Первый и повторные uncached запуски отмечены отдельно: это не
проверка warm cache. Трассировка сама влияет на время; native memory/RSS и
браузерный отклик не измеряются. Малый корпус проверяет воспроизводимость и
неудобные структуры, а не промышленную производительность.

Louvain и Leiden получают одну неориентированную проекцию с суммой двух
направлений и одинаковым resolution/seed. SArF simple получает исходное
направление и D(A,B)=1/fanin(B) (fanin — число различных единиц-источников).
Счётчики raw dependencies, типы и исходные IDs сохраняются для оценки и
provenance; в simple dedication multiplicity не переносится в fanin.

SArF реализует greedy agglomeration направленного Q и извлечение лучшего
среза из полной последовательности слияний. Это не member-level DM и не
повторение эксперимента статьи. Изоляты сохраняются отдельно — явная
адаптация для Atlas. Параметр resolution сравнения относится к Louvain/Leiden,
SArF использует γ=1. Неподходящий backend даёт unavailable без fallback;
для кубического simple greedy действует отдельный бюджет 200 единиц.

Источники: [SArF, III.A–C](https://arxiv.org/abs/1306.2096),
[Leiden](https://doi.org/10.1038/s41598-019-41695-z). Направленное значение Q,
плотность, размеры и coupling оцениваются раздельно и не заменяют экспертную
оценку смысловой целостности. Отсутствие циклов не утверждается при partial
coverage; незахваченные зависимости не считаются нулевыми.
