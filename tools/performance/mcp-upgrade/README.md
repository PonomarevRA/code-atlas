# Проверка условий обновления MCP core

Запуск из корня: `.venv/bin/python tools/performance/mcp-upgrade/probe.py`.

Это ограниченная проверка готовности ATL-224. Она читает реальные SDK descriptors, проверяет стабильность отпечатка при перестановке списка и обнаружение изменения схемы. Отдельный короткоживущий процесс пытается захватить ProcessLock только в новом временном каталоге; после освобождения владелец допускается. Установленные приложения, живые locks, карты и соединения не изменяются.

PASS относится к этим пробам. Он не означает бесшовное обновление ядра. Один и тот же набор tools не доказывает совместимость внутреннего HTTP API, смысла результата, состояния или storage. Текущий CLI сохраняет единственного владельца каталога данных; запуск двух полных cores с одним store не поддерживается. Обходить lock нельзя.

Следующий архитектурный шаг — отдельные read-only compute workers либо проверенная передача владения единственного writer. После этого нужны dispatch leases, drain, принадлежность jobs/cursors/subscriptions, обработка отмены и идемпотентность мутаций. Нативная поставка дополнительно требует exact-byte frozen-reader proof.

Результат `seamlessCoreUpdateQualified: false` намеренный. Воспроизводимое положительное исследование отдельных предпосылок не заменяет отсутствующие гарантии.
