# Модуль справочника паттернов

`atlas.code_patterns` — встроенный модуль приложения Atlas. Его ответственность —
валидировать локальные карточки, находить кандидатов и возвращать точную редакцию
паттерна. Модуль не зависит от проекта, графа, HTTP или MCP и не исполняет примеры.

## Публичный интерфейс и состояние

Потребители импортируют `PatternCatalog` и `PatternCatalogError` из
`atlas.code_patterns`. Основные операции — `search(...)` и `get(...)`; идентичность
каталога доступна как `catalog_version`. Параметр `root` задаёт доверенная сборка
или композиция приложения, а не запрос пользователя.

`create_app` создаёт один каталог в `app.state.code_patterns`. Каталог загружает и
проверяет ресурсы при создании, владеет неизменяемым содержимым своей редакции и
возвращает независимые значения. Изменение JSON-файла не обновляет существующий
экземпляр. Новая редакция требует нового экземпляра; горячая смена поколения
приложения в этом модуле не реализована.

## Границы

| Часть | Ответственность |
| --- | --- |
| `resources/code-patterns/*.json` | Единый версионированный источник карточек |
| `schema.py` | Форма, ограничения и ошибки карточек |
| `catalog.py` | Загрузка, bounded поиск, точное чтение и hash |
| `wiki.py` | Детерминированная проекция того же каталога для сборки wiki |
| `atlas/pattern_catalog_api.py` | HTTP-параметры и отображение ошибок |
| `atlas/pattern_catalog_mcp.py` | MCP-контракт и бюджет ответа |
| `scripts/build_project_wiki.mjs` | Включение проекции в существующую сборку wiki |

Статус карточки и квалификация её применения в проекте различаются. Поиск
возвращает кандидатов; чтение не подтверждает внедрение. Ссылки с версией, hash
или редакцией каталога проверяются явно, без подмены на текущую карточку.

Проверки: `tests/test_code_patterns.py`, `tests/test_pattern_module_adapters.py`
и `tests/test_pattern_module_mcp.py`; parity сборки —
`node scripts/build_project_wiki.mjs --check`.

Это граница класса/папки с ясной ответственностью. Существующий механизм `mods`
предоставляет иной контракт расширений; отдельный устанавливаемый или
отключаемый плагин справочника здесь не объявляется.
