# Контракт анализа модулей

Папка — самостоятельный вычислительный модуль, не зависящий от HTTP, MCP,
DOM, хранилища или запуска анализируемого кода. Публичные функции:

- `project_modules(graph, level='folder', folders=None, ownership=None, snapshot_id=None)`
  строит непересекающуюся class/folder проекцию с исходными IDs и coverage.
- `assess_partition(projection, partition=None)` проверяет полное разбиение и
  возвращает наблюдаемые факты, без общего искусственного балла.
- `compare_partitions(projection, algorithms=..., seed=42, resolution=1)`
  возвращает read-only предложения и причины недоступности отдельных providers.

`ModuleAnalysisError` имеет `code` и `status`: invalid input — 400,
превышенный бюджет — 413. Полный вход ограничен 10 000 узлов и 50 000 рёбер.
При явном folder frontier исходная карта может иметь до 100 000 узлов и
500 000 рёбер; выбранная часть ограничена 10 000 raw nodes, 50 000
dependency/boundary facts и 2 000 единиц. Это защитные бюджеты реализации,
а не доказанная производительность на максимальном объёме.

Class ownership берётся из явного kind класса, captured member owner и
containment. Labels не используются для угадывания типа. Общая
`classIdentity` объединяет несколько partial declarations; без такой
идентичности одинаковое имя класса не является доказательством эквивалентности.
Caller может передать raw ID → stable type identity mapping; её происхождение
помечено `caller-supplied`, а не выдано за доказанный source binding.
Вложенный класс владеет своими методами независимо от внешнего класса.
Функция Python без класса остаётся unknown в class mode; folder mode позволяет
оценить содержащую её декомпозицию без искусственного класса.

Проекция различает dependency и containment relations. Для допустимых
dependency relations общий confidence/source-hash gate из существующего
`code_health_calls` отвергает explicit uncertainty и stale source hashes.
Этот gate не доказывает семантическую полноту binding: происхождение рёбер
остаётся captured static. Дедупликация относится к полностью одинаковому
факту; два различных call sites сохраняются. Каждое агрегированное ребро
имеет исходные endpoints и hash факта. Исходный граф не изменяется.

Полнота требует явного `analysisStatus: complete` в источнике и отсутствия
неизвестного владения/зависимостей. Partial и отсутствие статуса дают partial.
Циклы считаются только между единицами выбранной области; при partial нельзя
утверждать их отсутствие. Внешние зависимости и неопределённые facts
показаны отдельно. Отсутствие связи в captured graph не означает отсутствие
runtime зависимости.

При partial coverage только абсолютные счётчики принятых зависимостей
могут быть нижними границами для фиксированной области и владельцев.
Q, плотность и другие нормированные величины — наблюдаемые значения, не
нижние или верхние границы: добавление скрытых связей может изменить их
в любую сторону. Например, singleton Q для a→b равна0, а добавление b→a
даёт−0.5 при том же разбиении. Это не ухудшение программы, а другая полнота
исходного наблюдения.

Q и плотность считаются по inter-unit графу. Внутренние raw dependencies
единицы не стираются: они представлены `withinUnitDependencyWeight` и входят
в общий `internalDependencyWeight`. Плотность — доля занятых направленных
пар единиц, не функциональная cohesion. H/O/T и default карты не меняются.

`current` сохраняет текущие class/folder единицы отдельными группами.
Louvain/Leiden используют одну undirected проекцию с суммой направлений.
`sarf-simple-directed` использует отдельную направленную dedication проекцию,
γ=1 и full greedy merge sequence. Это simple SArF адаптация из первичной
статьи, не member-level DM и не воспроизведение её экспериментального выигрыша.
Формулы, oracle и ограничения corpus — в
`tools/performance/module-analysis/README.md` и regression tests.

ID/hash/version/scope связывают результат с входом, а не с текущим содержимым
папки. Полные исходные IDs доступны библиотечному consumer. UI/MCP обязан
ограничить выдачу отдельно и явно сообщить усечение; библиотечные unknown и
outside ID lists ограничены 256 записями с независимыми count/truncated.
