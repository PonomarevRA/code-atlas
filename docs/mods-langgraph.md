# Локальные исследования и документация

Два встроенных, отдельно включаемых мода используют настоящий LangGraph:

- `langgraph-guide` — собирает факты вокруг выбранного символа или лексического запроса;
- `automatic-documentation` — использует тот же сборщик и оформляет факты в Markdown. Требует включённый `langgraph-guide`.

В первой версии модель не подключена. Нет смыслового ответа на произвольный вопрос, генерации объяснений, автоматического импорта справочников или сетевых запросов. Вопрос задаёт область лексического поиска. Комментарии остаются утверждениями автора, связи карты — статическими связями, реализации — кандидатами. Их корректность и фактический выбор при исполнении не утверждаются.

## Как пользоваться

1. Откройте «Моды», включите `langgraph-guide`, затем `automatic-documentation`. Включение закрепляет отпечаток всего пакета; изменение содержимого требует повторного включения.
2. Откройте процесс в карточке мода или пункт «Разобраться в проекте» в меню. Выберите проект и процесс.
3. Найдите имя метода, выберите символ, задайте вопрос и границы обхода. Можно перейти с карты: страница сохраняет параметры `repo` и `node`.
4. Запустите сбор. Результат показывает комментарии, дерево локального тела, статические связи, выдержки исходников и уже импортированных справочников. Раскройте источники для проверки хэшей и выдержек.
5. Скачайте Markdown. Проверка свежести повторно читает исходники, но не переписывает сохранённый документ. После изменения исходников или снимка создайте новое исследование.

Проектные файлы не изменяются и не исполняются. Языковая документация и библиотечные справочники ищутся только локально, в полнотекстовом режиме. Найденная выдержка не доказывает применимость API к конкретному вызову.

## Ограничения и восстановление

Один отдельный рабочий поток; до четырёх принятых запусков, 12 символов, глубина 3, 24 источника и 512 КБ фактов на запуск. Выдержка исходника ограничена 80 строками / 6000 знаками. Сокращения обозначаются явно. Хранилище ограничивает создание новых запусков после 500 записей или 128 МиБ базы записей; это не квота всей папки с checkpoints.

Запуск сохраняет снимок карты, отпечаток мода, версию процесса и хэши прочитанных файлов. Отмена запрещает публикацию. После перезапуска прерванный процесс продолжается только по команде пользователя. SQLite checkpoints и идентификаторы источников позволяют повторять прерванный шаг без дублирования. Завершённый документ неизменяем; новый запрос создаёт новую запись. Данные находятся в `<data-dir>/research/`.

## Контракт модов API v1

Опциональный раздел `workflows` расширяет декларативный manifest:

```json
{"apiVersion":1,"id":"my-local-guide","name":"Мой помощник","version":"1.0.0","workflows":[{"id":"explore","label":"Собрать факты","engine":"langgraph","kind":"research"}]}
```

`kind` принимает `research` или `documentation`. Это встроенные процессы хоста, а не произвольный исполняемый Python из мода. Пакет может объявить до восьми процессов с уникальными `id`. Зависимости задаются существующим `requires`. Моды не меняют Graphify и не получают дополнительные права исполнения через `workflows`.

`atlas/research/` разделяет записи SQLite, сбор доказательств, композицию документа, граф шагов, очередь и HTTP API. Сервисы карты, языковых и библиотечных справочников используются совместно с приложением. LangGraph импортируется только при запуске исследования; tracing отключён даже при настройках окружения. Для фонового восстановления применяется [SQLite checkpointer LangGraph](https://docs.langchain.com/oss/python/langgraph/persistence).

HTTP: `/api/research/capabilities`, `/api/research/runs`, `/api/research/runs/{id}`, а также `cancel`, `resume`, `freshness`, `document.md`. POST создания требует `projectId`, `snapshotId`, `modId`, точный `fingerprint`, `workflowId`, `nodeId` или `question`, и уникальный `requestKey`. Повтор того же ключа с тем же телом возвращает существующий запуск; изменение тела с тем же ключом отклоняется.

Будущее подключение генерации требует отдельного выбора модели, политики отправки кода, проверки ссылок и смыслового ревью. В этой версии таких подключений нет.
