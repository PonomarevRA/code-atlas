# Общая шапка и регулируемые панели 0.2.0

Подключены фиксированные локальные @ag-design/components и @ag-design/rules 0.2.0; host palette сохранена. Точки интеграции и элементы перечислены в ag-design.integration.json. bindWindowShell переносит существующие команды, следит за выбранным разделом/сущностью, использует историю продукта и отключает недоступные переходы. bindResizablePanel даёт drag/Arrow/Home/End на внутренней границе существующих панелей; свёрнутые рейки сохраняют свою сторону и ширину.

macOS: настоящая нативная шапка и фиксированные команды, null-only owned-main-frame notifications, HTML fallback скрывается только после native-window-commands. При недостатке места или сбое capability он возвращается. Windows/Linux: web fallback; запуск на этих ОС не выполнен. Избегайте переноса кнопки, если её обработчик делегирован контейнеру, который перестанет быть предком: сначала адаптируйте владельца события.

Проверены source/backend/UI контракты и отдельный ARM64-кандидат. Захват native screenshots недоступен из-за ScreenCaptureKit -3811; native visual review остаётся обязательным перед внешним выпуском. Полный отчёт и методика: ag-design/docs/design-v2-verification.md. Внедрение в рабочую установленную копию — отдельный шаг; текущий source change не доказывает обновления запущенного приложения.
