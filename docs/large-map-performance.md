# Производительность больших карт

Оптимизация сохраняет состав графа, точную проверку пересечений, плавные связи,
локальное раскрытие и доказательства переходов. Она не ограничивает число узлов.

`web/rectangle-index.js` отбирает ближайшие препятствия по их оболочкам. Точная
проверка кривой и A* остаются прежними. Индекс учитывает открытые границы портов
и подписи, появляющиеся во время построения сцены.

`web/path-route-cache.js` повторно использует маршруты одной геометрии в одном
GraphView. Изменение snapshot, корневого метода, провайдера или координат сбрасывает
кэш. Порядок маршрутов также проверяется: внешние порты заглушек дополняют сетку,
поэтому при изменении последовательности её прежний префикс воспроизводится.

Карта запрашивает `GET /api/projects/{id}/graph?algorithm=natural&projection=map`.
Эта проекция исключает только `nodes[].attributeFacts`; описание узла получает
подробные атрибуты отдельно. Поля, комментарии, отдельные узлы атрибутов и все
рёбра остаются. Полный ответ по умолчанию и MCP сохраняют прежний контракт.
JSON сериализуется один раз вместо дополнительного обхода FastAPI encoder.

## Воспроизводимый CPU-замер

Сохраните полный ответ `/graph` и ответ `/execution-path` для одного снимка.
Путь должен содержать `rootNodeId`, `steps` и `edges`. Затем выполните:

```sh
node tests/benchmark_execution_path.mjs /tmp/graph.json /tmp/path.json
```

Третий аргумент позволяет указать каталог JS предыдущей версии. Сравнение
запускайте последовательно на одинаковых входных JSON, без параллельной нагрузки.
Замер возвращает медианы трёх сцен: начальная, частичная и полная. SHA-256 всех
маршрутов позволяет сравнить геометрию до и после. Отдельно измеряется повторная
отрисовка без изменения геометрии. SVG fixture не измеряет layout, paint или FPS
настоящего браузера. HTTP-время измеряется отдельно.

Результат проверки CostChange с 457 методами и исходным графом 12800 узлов /
27816 рёбер сохранён в `outputs/large-map-performance.json`. Полное раскрытие,
фильтр условий и фокус на выбранном методе также проверены в браузере на отдельном
предпросмотре; установленный пакет этим изменением не заменялся.
