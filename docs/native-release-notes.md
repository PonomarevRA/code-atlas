### Install Code Atlas

Download the installer for your operating system and CPU from **Assets**. Each download has a matching SHA-256 file. The application includes its own Python runtime.

- **macOS** — open the DMG and run Code Atlas Setup. This community build is ad-hoc signed and has no Apple notarization.
- **Windows** — run the Setup EXE. The community installer is unsigned.
- **Linux** — extract the TAR.GZ and run `./Setup` from the extracted directory.

Only platforms with a downloadable installer are available for this release. For other platforms, use the source installation guide.

### Установка Code Atlas

Выберите в **Assets** установщик для своей ОС и процессора. Рядом с файлом опубликована контрольная сумма SHA-256. Python уже входит в приложение.

- **macOS** — откройте DMG и запустите Code Atlas Setup. Сборка имеет локальную подпись и выпущена без нотарификации Apple.
- **Windows** — запустите Setup EXE. Установщик сообщества выпущен без подписи.
- **Linux** — распакуйте TAR.GZ и выполните `./Setup` в распакованном каталоге.

Если для вашей платформы пока нет установщика, воспользуйтесь инструкцией установки из исходников.
