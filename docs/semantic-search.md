# Локальный поиск комментариев и документации

Code Atlas сохраняет отдельный снимок документов в LanceDB. Запрос RU/EN возвращает
короткие выдержки, файл, строки, косинусное расстояние и существующие raw-ID кода.
Агент получает только найденные фрагменты вместо полной документации репозитория.
Сервис не генерирует объяснения и не отправляет запросы или код во внешние API.

## Подготовка

Установите зависимости из `requirements.lock`. Затем **однократно** загрузите
официальные веса локальной модели:

```sh
.venv/bin/python scripts/prepare_semantic_model.py
```

Используется [paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2):
384 измерения, 50 языков, включая русский и английский. FastEmbed запускает
квантованную ONNX-модель на CPU. Подготовка загружает только веса и tokenizer;
комментарии проекта она не читает. Индексация и поиск загружают только уже
имеющиеся файлы (`local_files_only=True`). Без модели карта продолжает работать,
а панель поиска показывает недоступность модели.

По умолчанию кэш находится в `<data-dir>/models`. Для обычной установки macOS:
`~/Library/Application Support/Code Atlas/models`. Для отдельного каталога данных
передайте `--cache-dir` скрипту или задайте `ATLAS_EMBEDDING_CACHE` при запуске
приложения. Кэш можно перенести с подготовленного компьютера для полностью
автономной установки.
Скрипт превращает внутренние ссылки Hugging Face в обычные файлы с теми же
байтами, чтобы штатная ZIP-копия Atlas могла сохранить модель. Для кэша,
подготовленного раньше, это можно сделать без сети:
`.venv/bin/python scripts/prepare_semantic_model.py --materialize-only`.

## Использование

Откройте проект и раздел «Поиск по комментариям и документации».
Нажмите «Построить индекс документов», дождитесь завершения и введите, например,
«Как выбирается валюта портфеля?». Выберите область: комментарии, документация
или оба источника. Кнопка «Открыть код» ведёт к подтверждённому узлу карты;
предыдущий вид остаётся доступен через «Назад» браузера.
Первый поиск после запуска лениво загружает локальную модель и библиотеку LanceDB;
последующие запросы используют уже загруженные зависимости. MCP ждёт такой поиск
до 60 секунд, обычные запросы сохраняют прежний 30-секундный предел.

При новой публикации карты сервис запускает отдельный фоновый индекс, если
локальная модель доступна. Если writer занят, сервис сохраняет последний снимок
каждого проекта со статусом `deferred` и запускает его после текущей задачи.
Обновить документы без пересборки
карты можно кнопкой «Обновить снимок документов». Поиск ничего не переиндексирует
и не перечитывает исходные файлы. Изменения рабочего каталога после захвата
попадут в поиск только при следующем обновлении индекса.

## Источники и границы

Корпус содержит C# комментарии/XML-документацию из безопасно прочитанных файлов
карты, Markdown из карты и ограниченного каталога README/docs, а также сохранённые
Graphify rationale и описания модулей. Тела методов целиком не векторизуются.
Источник каждого фрагмента явно обозначен: рабочая копия на момент захвата либо
сохранённый граф. `capturedAt` и SHA-256 источника фиксируют происхождение текста;
это не заявление о Git-коммите рабочего каталога.

Привязка к коду основана на объявлении или исходной связи `rationale_for`/`documents`.
Упоминание имени метода в документе само по себе не создаёт вызов или связь.
Документ без прямой связи всё равно можно найти; UI сообщает отсутствие связи.
Документы и комментарии рассматриваются как данные, не как инструкции агенту.

Корпус ограничен 6000 фрагментами, 1500 файлами, 1 МиБ на файл, 24 МиБ суммарно.
Ограничения и пропуски отражаются в метаданных. Текст дополнительно разбивается
локальным tokenizer под бюджет модели (128 токенов с учётом служебных токенов).
Меньшее косинусное расстояние означает близость по смыслу, **не вероятность**
и не доказательство того, что код делает описанное. Качество ранжирования
зависит от содержимого комментариев и документации.

## Wiki выбранного узла

Wiki показывает отдельно документы с захваченной привязкой к узлу или файлу,
документы настоящих соседей на один шаг существующего графа и рекомендации
по сходству текста. Для соседей сохраняются направление, relation и confidence
исходного ребра. Сходство не добавляет вызовы и не доказывает поведение реализации.
Точные Markdown-ссылки на исходный файл обозначаются как привязки уровня файла;
упоминания имён и примеры внутри code blocks не становятся связями.

Полные документы захватываются вместе с embedding-фрагментами и публикуются
одним generation в LanceDB. Просмотр читает сохранённый текст по `documentId`,
не открывает переданный путь и не перечитывает рабочую копию. Пагинация использует
смещения символов, до 12000 символов на страницу. Для прямых привязок и просмотра
не нужна загруженная модель; недоступность рекомендаций сообщается отдельно.
Старый индекс без полных документов требует обновления и возвращает 409.

Захват ограничен 2000 документами, 128000 символами и 512 КиБ на документ,
16 МиБ текста суммарно, 40 явными ссылками на документ и 60000 привязками индекса.
Бюджет embedding-фрагментов остаётся отдельным: длинный текст можно прочитать
полностью в пределах захвата, даже когда его embedding-часть усечена.
Ограничения, `capturedAt`, `sourceHash` и происхождение сохраняются в ответе.

## HTTP и MCP

Все запросы привязаны к `projectId` и опубликованному `snapshotId`; смена снимка
до выдачи ответа приводит к 409. Неудачный индекс не повреждает карту.

```text
GET  /api/projects/{id}/documentation-index?snapshotId={snapshot}
POST /api/projects/{id}/documentation-index
     {"snapshotId":"...","force":false}
GET  /api/documentation-index/jobs/{jobId}
POST /api/projects/{id}/semantic-search
     {"snapshotId":"...","query":"валюта портфеля","limit":8,"kind":"all"}
POST /api/projects/{id}/node-wiki
     {"snapshotId":"...","nodeId":"...","limit":8}
POST /api/projects/{id}/wiki-document
     {"snapshotId":"...","documentId":"...","offset":0,"maxChars":12000}
```

MCP-инструменты: `index_documentation`, `get_documentation_index`,
`search_documentation`. Последний возвращает до 20 выдержек и ограничивает
ответ 64 КБ UTF-8. MCP остаётся прокси к локальному серверу, второй writer
в stdio-процессе не создаётся.

## Модули и хранение

`atlas/document_corpus.py` отвечает за захват источников;
`atlas/semantic_embeddings.py` — за локальную модель и tokenizer;
`atlas/semantic_index.py` — за таблицы LanceDB, кэш векторов и публикацию manifest;
`atlas/semantic_service.py` — за очередь задач и проверку карты.
`atlas/wiki_service.py` разделяет source associations, соседей графа и semantic
recommendations, а также выдаёт страницы захваченного текста.
Данные находятся в `<data-dir>/semantic`, отдельно от Graphify-снимков.
Одинаковые тексты переиспользуют векторы при совпадении fingerprint модели и
правил обработки; привязки к проекту, снимку и узлам сохраняются отдельно.
Индексирование и запросы имеют локальную стоимость CPU/диска, платы за API нет.
Сравнение фактических LLM-затрат до/после не выполнялось.
