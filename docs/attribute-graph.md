# Атрибуты в общей карте и MCP

При новой сборке Code Atlas сохраняет лексические C#-атрибуты в опубликованном
снимке. Они доступны через поиск узлов, соседство, сохранённые виды и MCP.
Изменение рабочего файла не переписывает факты старого снимка.

Каждое вхождение — отдельный узел `kind: attribute` с ID в пространстве `attr:`.
Узел содержит имя, текст и выражения аргументов, target, область действия,
владельца, файл, строки и хеш захваченного исходника. Повторные атрибуты остаются
отдельными вхождениями. Исходные ID Graphify сохраняются.

Связь `has_attribute` идёт от установленного лексического владельца к атрибуту.
Если параметр не представлен отдельным исходным узлом, его объявление связано
с атрибутом через `has_parameter_attribute`: поле `scope: parameter` и имя
параметра явно отличают его от атрибута метода. Для `assembly/module` может быть
создан контейнер `attribute_scope` файла. Неоднозначный владелец не угадывается.
Контекстные группы `attributeFacts` на исходных узлах содержат ссылки на
вхождения, отдельно показывая атрибуты объявления, содержащих типов, параметров
и файла. Эти отношения не являются вызовами.

Агентский MCP предлагает:

1. `search_nodes(query="HttpPost")` — найти вхождения и получить `snapshotId`.
2. `get_node(snapshotId, nodeId)` — прочитать сохранённые факты, включая аргументы.
3. `get_neighbors(snapshotId, nodeId, direction="outgoing", limit=40)` — пройти
   связи объявления. Поддерживаются `incoming`, `outgoing`, `both`; до 120 связей.
4. `create_view(...)` — сохранить выбранные узлы и связи для совместного просмотра.

Ответы ограничены бюджетом MCP; `truncated` сообщает сокращение. Устаревшая
ревизия отклоняется. `describe_node` продолжает читать ветви и документацию из
рабочего дерева, но захваченные атрибуты возвращает с отдельным
`sourceKind: snapshot-captured-source` внутри `attributeFacts`.

Для Graphify MCP при сборке создаётся отдельный `mcp-graph.json` с теми же
узлами и отношениями общей карты. Оригинальный raw JSON Graphify сохраняется.
Публикация обоих файлов завершается до переключения ревизии. Старые карты без
этого файла используют прежний raw-контракт до пересборки. Graphify сокращает
текстовый вывод свойств; полные структурированные факты доступны через
агентский `get_node`. Поиск Graphify исследует соседство в обе стороны и не
доказывает порядок исполнения.

Это анализ синтаксиса: значения аргументов, разрешение типа атрибута, наследование,
другие части partial-объявлений и влияние на выполнение не вычисляются.
`metadata.attributeGraph` фиксирует версию, происхождение, лимиты, предупреждения
и полноту захвата.

При обновлении native-версии используйте `python packaging/build.py --clean` и
проверяйте её настоящий MCP после установки. Одного успешного прогона исходников
недостаточно: кеш PyInstaller может сохранить прежний архив Python. Числовые
номера групп в совместимом MCP-файле имеют исходные ID в `atlasCommunityId`.
