# Чтение методов внутри карты класса

Круг `+` у метода или конструктора раскрывает тело в текущей SVG-карте.
Стрелка остаётся переходом к отдельной полной цепочке. Класс/файл сохраняют
структурное раскрытие, и соседние карточки раздвигаются вокруг занятой области.

Тело использует `buildPathScene` и дерево условий пути от входа: `if`, `switch`,
циклы, вызовы, выходы и объявления словарей. У сопоставленного вызова есть
«Раскрыть здесь». Каждое вхождение имеет отдельный presentation ID; запросы
к API и переходы к исходнику используют подтверждённые исходные ID.

Конструкторы имеют подпись «при создании объекта», статические конструкторы —
«запуск типа», обычные методы — «отдельный вызов». Пропущенные Graphify явные C#
конструкторы добавляет ограниченный AST-pass. `base(...)` связывается с единственным
подходящим объявлением родительского конструктора; перегрузки не угадываются.
Неявные/primary конструкторы этим дополнением не синтезируются. Отложенные
вызовы внутри lambda помечаются отдельно и не становятся прямыми constructor-body
рёбрами. Анализ не запускает код и не доказывает runtime-порядок.

В примере `SecurityPrioritySorter.cs` конструктор вызывает родительский
`SecurityPrioritySorter<T>` из `SecuritySorter.cs`. В родительском конструкторе
видны `foreach`, проверки типов и рынков, `AddMoexSecurity`/`AddSpbSecurity` и
чтение `CurrencyPriority`. В `GetMoexBoardPriority` доступны словари режимов MOEX,
включая ETF. Пары `BoardCode → приоритет` являются исходными выражениями снимка;
фабрики и ссылки на константы не вычисляются.

Описания загружаются только при раскрытии, проверяются по project/snapshot/node,
отменяются при смене области. Кэш ограничен 32 описаниями. На карте разрешены
8 раскрытых корневых тел; внутри каждого — до 8 вхождений с глубиной 3 и до
160 карточек деталей. Усечения отмечены явно. Индекс чтения полей переиспользуется
для объекта графа, готовая геометрия тела — для неизменных фактов и раскрытий.
Камера сохраняет нажатую карточку при ответе API; анимация уважает reduced-motion.
Раскрытия сохраняются в существующей истории вкладки, свежий снимок их сбрасывает.

Проверки: `tests/test_constructor_structure.py`, `tests/test_inline_method_body.mjs`,
`tests/test_map_blocks.mjs`; тесты настоящего GraphView и просмотра пути продолжают
проверять исходные IDs, поля, выделение, геометрию и навигацию.
