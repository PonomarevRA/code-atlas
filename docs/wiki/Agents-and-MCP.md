# Агенты и MCP

[Справочник паттернов](Code-Patterns.md) помогает выбрать границы классов/папок и
контракты. Сначала прочитайте [как выбирать паттерн](Pattern-Selection.md).
Совместимое обновление MCP-ядра пока описано как [рецепт для квалификации](MCP-Compatible-Updates.md),
а не как подтверждённая возможность установленного Atlas.

Панель **Для агентов · Cursor / MCP** выдаёт конфигурацию выбранного репозитория, SKILL.md и ZIP. Объедините запись `mcpServers` с конфигурацией клиента, сохранив другие серверы. Распакуйте skill в каталог клиента; в Cursor вызовите `/code-atlas`.

В каталоге `/api/agent-setup/skills` доступны общие пакеты `code-atlas` и
`code-atlas-engines`. Они подходят Codex, Cursor, Claude Code, DeepSeek Harness
и клиентам с поддержкой Agent Skills. Для других агентов доступны Markdown
и HTTP-инструкции через `/agent-setup.md`. В checkout проекта список навыков
и установщик описаны в `skills/README.md`.

Агент предлагает подходящий отсутствующий пакет, проверяет имеющееся разрешение
на установку и сохраняет локальные изменения. Навык движков проверяет фактические
запросы и опубликованные факты и помогает настроить изолированные окружения.

## Найти факт и раскрыть подробности

Начните с `list_projects` и `search_nodes`, затем передавайте полученные `nodeId` и `snapshotId` в `describe_node`. ID — машинная идентичность, label — подпись; одинаковое имя не доказывает связь. Текущий исходник может отличаться от снимка. Заметки и авторские объяснения должны оставаться отличимыми от извлечённых фактов.

Для большого окружения узла используйте `get_neighbors`. Если ответ содержит `nextRef`, передайте его как `cursor` с теми же проектом, снимком, узлом и направлением. Продолжайте до `nextRef: null`; лимит страницы не означает, что прочитан весь список. Изменение области делает старую ссылку недействительной.

Разделы большого описания раскрываются через `get_analysis_section`: `methodFlow`, `documentation`, `calls`, `controlFlow`, `parameterFacts`. Используйте выданный `sectionRef`; `items[].ref` раскрывает отдельный элемент, `nextRef` продолжает страницу. Не восстанавливайте ссылки вручную. Описания пересчитываются с текущими зависимостями: изменение другого файла тоже может инвалидировать продолжение. После конфликта обновите описание и получите новую ссылку.

По файлу и строке используйте `get_position_dependencies`, а в отдельной рабочей
карте — `get_checkout_position_dependencies`. По умолчанию два уровня callers/callees;
направления обходятся независимо. [Контракт и ограничения](Position-Dependencies.md).

## Оценки здоровья кода

В краткой карточке метода доступны оценки из снимка. Для отчёта используйте
`get_code_health_report`, для измерения рабочей копии — `get_code_health`.
Поля оценок, признаки неполноты и порядок сравнения описаны в
[Оценках для агентов через MCP](Code-Health.md#оценки-для-агентов-через-mcp).

## Временный рабочий контекст

`open_analysis_context` возвращает `contextId` для повторного чтения AST через `get_method_flow_chunk` и раскрытия разделов через `get_analysis_section`. Передавайте его в запросах и закрывайте через `close_analysis_context`. Полезное успешное чтение продлевает срок до 20 минут бездействия; без обращений контекст истечёт. Это ограниченный RAM-кэш синтаксиса выбранных файлов, постоянная история снимков сохраняется отдельно.

AST-страница с `analysisKind: syntax-outline` и `flowStatus: not-computed` показывает синтаксис, а не вычисленный путь исполнения. Догрузка не устраняет `UNKNOWN`, неподдерживаемые конструкции или усечение исходного анализатора. Проверяйте coverage и предупреждения перед выводами об отсутствии вызовов.

## Карта результата и подключение

`create_view` и `get_view` сохраняют выбранные реальные узлы и связи для объяснения. Для неразмеченного symbol нельзя угадывать, что узел — поле; исключайте проверенные ID явно.

Standalone MCP использует executable приложения, поэтому отдельный Python не нужен. Atlas должен работать на том же компьютере. После изменения пути установки или порта обновите JSON. Ограничение выбранного проекта действует в инструментах; оно не заменяет авторизацию ОС. Cloud-агент не видит localhost вашего компьютера.

Встроенные языковые, framework и semantic-моды могут расширять анализ. Их wiki объясняют входы и ограничения; чтение wiki не включает мод и не подтверждает успешный запуск движка.
