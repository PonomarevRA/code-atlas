# Пример: какой тест объявлен с какими данными

Ниже — вымышленный Java-проект `example-java-tests` с классом `OrderTests`.
Имена и значения иллюстрируют работу интерфейса; результаты реального проекта
или запуска тестов здесь не публикуются.

## Путь человека

1. Постройте карту своего QA-проекта с включёнными `language-java` и подходящим framework-модом.
2. В каталоге «Точки входа» выберите тип «Тест» и найдите нужный класс.
3. Откройте тест, затем раздел «Данные и варианты»: таблица показывает имена параметров и источник.
4. Выберите строку для изучения. Это действие не запускает тест.
5. Проверьте «Контекст и преобразование аргументов»: lifecycle и расширения не являются дополнительными ячейками набора.
6. «Все тесты класса» возвращает к владельцу теста.

## Примеры источников

- `validateOrder`: `MethodSource` объявляет наборы входных значений; отсутствующий ключ и `null` различаются.
- `retryCount`: `ValueSource(ints = {1, 2, 3})` задаёт три значения параметра `attempts`.
- `currencyPair`: `CsvSource` связывает исходные ячейки с параметрами в порядке объявления.
- `orderStatus`: `EnumSource` использует объявленные константы; неподдержанный фильтр остаётся неизвестным.

Atlas показывает только распознанные статические данные. Наличие этих возможностей
не гарантирует разрешение произвольного провайдера в вашем проекте.

## Как это устроено в Atlas

JUnit-мод `mods/framework-junit5/mod.json` выбирает стратегию источника.
`atlas/test_discovery.py` находит объявления и владельцев, а
`atlas/test_dataset_contract.py` связывает исходные ячейки с параметрами.
Специализированные readers разбирают literal, CSV и enum.

`atlas/test_dataset_page.py` читает сохранённый снимок и отдаёт ограниченную
страницу. UI и MCP получают стабильные ID, параметры, строки, источники и
признаки усечения. `uses_test_data` означает использование источника данных.

## Ограничения

Объявление набора не доказывает успешный запуск теста или фактические данные БД.
Сложный провайдер, converter, HTTP-вызов или SQL может требовать дополнительного
адаптера и ручного чтения. Неизвестные значения не подменяются выдуманными.
