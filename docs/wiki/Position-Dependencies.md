# Зависимости по файлу и строке

Сверено по исходникам: 2026-11-13.

Инструмент даёт локальный контекст для чтения кода: из позиции в сохранённом файле
находит объявление и проходит ближайшие вызовы. Это основа для будущего расширения IDE;
автоматического чтения курсора, подсветки редактора и исправлений сейчас нет.

## Запрос агента

Для работы над checkout сначала создайте отдельную временную карту через
`ensure_checkout_map`, дождитесь её снимка и вызовите
`get_checkout_position_dependencies`. Для явно выбранного постоянного проекта
используйте `get_position_dependencies` с `projectId`.

```json
{
  "sessionId": "<из ensure_checkout_map>",
  "snapshotId": "<из get_checkout_map>",
  "file": "src/Orders/OrderService.cs",
  "line": 42,
  "depth": 2,
  "direction": "both"
}
```

Строки нумеруются с единицы. Путь — относительно корня проекта либо абсолютный
внутри выбранного checkout. Файл должен присутствовать в выбранном графе.
`expectedSourceHash` необязателен: SHA-256 сохранённых байтов файла позволяет
отклонить запрос от другой редакции редактора. Несохранённый буфер не принимается.

HTTP использует тот же JSON без `sessionId`/`projectId` в теле:

- `POST /api/projects/{projectId}/position-dependencies`
- `POST /api/checkout-sessions/{sessionId}/position-dependencies`

MCP, привязанный к постоянному проекту или карте данных, не получает доступ к
отдельным checkout-сессиям; нужен общий MCP без такой привязки.

## Глубина и направление

По умолчанию глубина — два ребра, диапазон — 1–8. `incoming` идёт к вызывающим,
`outgoing` — к вызываемым. `both` выполняет два самостоятельных направленных
обхода: он не идёт сначала к caller, затем к его соседнему callee. Циклы конечны,
raw-ID сохраняются. Учитываются `calls` и `dispatches_to`; владение классом/папкой,
импорты и доступы к полям не подменяются вызовами. Возможная реализация интерфейса
остаётся кандидатом, а зависимость не доказывает фактический путь выполнения.

Ограничения: по умолчанию 60 узлов/120 рёбер, максимум 120/240 и 64000 байт JSON.
При усечении уменьшите глубину/бюджеты и читайте выбранные узлы отдельно.
Проверяйте `truncated` и частичное покрытие самой карты: отсутствие ребра не
доказывает отсутствие зависимости.

## Что проверять в ответе

`status`, `anchorId` и `candidates` показывают результат сопоставления позиции.
Нельзя выбирать ближайший предыдущий метод, если строка не попадает в его диапазон.
Вложенные объявления и перегрузки требуют однозначной привязки; неизвестное
соответствие или изменившийся исходник не считаются точным попаданием.

Точное AST-сопоставление поддерживает C#, Python и функции JavaScript
(`.js`, `.jsx`, `.mjs`, `.cjs`). Для внешнего JavaScript парсер читает файл
целиком, а поиск обходит ветви AST на выбранной строке. HTML-мод индексирует функции внутри
встроенных JavaScript-блоков `<script>` и сохраняет их диапазоны в координатах
HTML. Запрос для HTML проверяет SHA-256 всего файла по снимку. Рёбра вызовов
показывают статические кандидаты для прямых вызовов по имени внутри одного блока.
Для других языков используется захваченный диапазон с совпавшим хешем,
если снимок содержит такой диапазон. Колонки отсчитываются с единицы в байтах
UTF-8. Клиент IDE переводит их в систему координат своего редактора.

`sourceProvenance` отделяет снимок графа от текущего файла. Совпадение хеша редактора
с текущим файлом само по себе не делает старую карту актуальной. При409 обновите
снимок или сохранённые байты; не подставляйте новый ID снимка в старый результат.

`sourceEvidence` содержит ограниченные исходные факты, доступные существующему
языковому анализатору. Их можно использовать для следующего вопроса агенту:
«передаётся ли здесь буквально null?» или «похожи ли эти проверки?».
Буквальный аргумент не доказывает нарушение контракта callee. Сходство условий
не доказывает, что повторная проверка лишняя: между ними могут быть изменения
состояния, побочные эффекты, ветвления или другой владелец значения.
Межпроцедурный анализ nullability и доказательство избыточности не реализованы.
Для прямых вызывающих сохраняется ограниченный исходный контекст: это позволяет
увидеть буквальный аргумент выше по графу, сохраняя условность и неоднозначность вызова.

Успешное полезное чтение временной карты продлевает её срок на час. Ошибки
валидации, устаревшего снимка и превышения бюджета срок не продлевают.
Инструмент не перестраивает карту, не переносит исходники и не сохраняет новую раскладку.
