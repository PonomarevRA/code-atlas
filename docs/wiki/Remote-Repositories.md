# Репозитории Git

В источнике карты выберите Git, укажите HTTPS/SSH URL и, при необходимости, имя
ветки или тега. Команда Git выполняется только по явному запросу; для этого шага
нужен доступ к Git-серверу. Последующий анализ работает локально.

Используйте настроенный Git credential manager или SSH agent. Не помещайте токен
или пароль в URL. Приложение не сохраняет пароль, не запускает команды сборки
репозитория, hooks, submodules или пользовательские checkout-фильтры.

Клон помещается в управляемый каталог рядом с базой знаний, а не внутрь .app.
Материализуются обычные файлы; symlinks и submodules пропускаются с предупреждением.
Задание ограничено по времени и объёму. Если индексация занята, путь готового
клона можно открыть как локальный проект. Существующие рабочие копии пользователя
не сбрасываются; автоматический pull поверх них не выполняется.

Для получения нового состояния используйте новый импорт либо собственный Git
в своей рабочей копии и «Обновить индекс». Удаление старых индексов не является
частью обновления приложения.
