## Задача

Трудно понять, на каком этапе потерялись данные или возник неизвестный результат.

## Когда применять

- Несколько самостоятельных шагов обработки.
- Стадии имеют разные ограничения и могут повторно использоваться.

## Когда не применять

- Пара коротких операций понятнее в одном методе.

## Граница класса или папки

Папка конвейера объединяет стадии; каждая стадия — связная функция или класс с одним назначением.

## Ответственность

- Назвать промежуточный результат.
- Указать причину partial/error и границы бюджета.

## Публичный контракт

normalize(values) -> нормализованные значения; compute(values) -> результат без повторной загрузки.

## Зависимости

- Оркестратор вызывает стадии по порядку.
- Стадии не вызывают UI и соседние внешние входы.

## Состояние и время жизни

Временные значения принадлежат одному запуску; большие потоки не копируются без необходимости.

## Ошибки

- Ошибка стадии сохраняет её название и не выдаётся за пустой успешный результат.

## Пример

```python
def run(values, normalize, compute):
    """Последовательно преобразует явно переданные значения."""
    normalized = normalize(values)
    result = compute(normalized)
    return result
```

Этапы названы и доступны для самостоятельной проверки.

## Контрпример

```python
def run(values, a, b, c, d):
    return d(c(b(a(values))))
```

Вложенная цепочка скрывает промежуточные состояния и место возникновения ошибки.

## Как внедрять

- Выделите фактически самостоятельные этапы.
- Опишите промежуточные значения и partial states.

## Ограничения

- Конвейер не требует облачных очередей или конкурентного исполнения.

## Что проверять

- Проверить каждую границу на пустом/неполном входе.
- Проверить сохранение порядка и ошибок.

## Альтернативы

- Оставить линейный метод, если разделение ничего не упрощает.

## Как писать код

- Описание метода объясняет вход, результат и существенные ошибки; комментарий ветви объясняет причину.
- Используйте ясные локальные этапы и ранние выходы; новый класс или интерфейс нужен только для самостоятельной ответственности.

## Применимость и версии

- python
- Примеры: синтаксис Python 3.12/3.13; типизированные интерфейсы не заменяют runtime-проверки.
