# Пример: агент задаёт вопрос Atlas

Вопрос: «Как агент найдёт нужный метод и проверит объяснение?»

## Последовательность исследования

1. `list_projects` даёт список зарегистрированных карт.
2. `search_nodes` ищет короткое имя или путь. Сохраните полученный snapshotId и точный raw ID.
3. `describe_node` объясняет доступные факты, комментарии, локальную сложность и тело метода. Проверьте sourceKind, усечение и предупреждения.
4. Если остаётся неоднозначность, прочитайте исходник указанного метода. Текущая рабочая копия может отличаться от снимка.
5. `create_view` сохраняет выбранные узлы, настоящие связи и отдельно подписанные пояснения автора. Полученную ссылку можно открыть человеку без повторного диалога с агентом.

## Где это реализовано

`atlas/agent_mcp.py:create_mcp` регистрирует инструменты. `atlas/mcp_transport.py:LoopbackTransport` отправляет запросы работающему локальному HTTP-сервису. Область выбранного проекта проверяется до запроса. Серверные feature-модули выполняют анализ; MCP ограничивает размер выдачи и сохраняет признаки неполноты.

Например, `get_test_data` и HTTP API тестовых данных используют общий snapshot-bound reader `atlas/test_dataset_page.py`. Это позволяет сравнить то, что видит агент, с таблицей в интерфейсе.

## Важное различие источников

Поиск символов идёт по сохранённой карте. Подробное описание некоторых элементов читает текущий файл; ответ помечает происхождение. Перед выводом «так работает сохранённая версия» проверьте sourceProvenance и хеш. Устаревший snapshotId нужно перепроверить, а не просто заменить в старом наборе ID.

Смысловой поиск находит похожий текст. Он может предложить старый исследовательский отчёт вместо актуального устройства системы. Для wiki нужно проверить первоисточник и объяснить переходы своим текстом.

## Маленький пример запроса человеку и агенту

```text
Объясни, как Atlas публикует новую карту.
Найди ProjectStore._build и create_app.
Отдельно покажи сохранённые факты, текущий исходник и авторские выводы.
Не запускай код исследуемого проекта.
```

В этом руководстве такой маршрут проверен на самом Atlas. Карта нашла нужные символы; рассказ о соединении компонентов дополнительно сверялся с исходником.
