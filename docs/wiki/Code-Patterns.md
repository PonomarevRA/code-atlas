# Паттерны проектирования и написания кода

Найдите подход к задаче, прочитайте точную карточку и проверьте её применимость. Модуль может быть самостоятельным классом или связной папкой; абстракция не обязательна сама по себе.

Это единый локальный справочник для wiki и агентов. Draft/reviewed карточки не подтверждают квалификацию конкретного проекта.

Catalog version: `3b1765c0fa5449368237cddb8631362e34807809260037307e3e8e95780f3fa5`.

## Границы доказательств

Каталог предлагает варианты, а не автоматический рефакторинг. Наличие паттерна, высокий score графа или совпадение схемы не доказывают архитектурную целостность. Все примеры — текст; загрузка wiki ничего не исполняет.
