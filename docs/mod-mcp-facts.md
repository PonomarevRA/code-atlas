# Данные языковых и библиотечных модов в MCP

Моды обогащают общий снимок карты. MCP читает те же захваченные факты; открытие поиска не исполняет моды, тесты или функции из анализируемого проекта.

`search_nodes` ищет по обычным именам/путям, а также по ограниченному набору захваченных названий тестов, меток, квалифицированных имён аннотаций, ссылок на провайдеры данных и build-манифестов. Тела исходников, произвольные выражения и все строки больших наборов данных не являются полнотекстовым индексом этого инструмента.

Результат содержит:

- `analysisFacts.language`: язык из захваченных фактов.
- `analysisFacts.project`: область проекта, build-манифест и свидетельство определения, включая `modId`, `modFingerprint`, `confidence` при наличии. Логическая папка не выдаётся за отдельный build-проект.
- `analysisFacts.test`: название, фреймворк, метки, объявленное состояние, состояние запуска, краткие источники данных, точные ID провайдеров и число объявленных строк. `preview`, `detailsAvailable` и `truncated` обозначают сокращение.
- `analysisFacts.annotations`: небольшой список имён и scope атрибутов с отдельным счётчиком общего количества.
- `analysisContext`: версия, fingerprint и ограниченный перечень провайдеров **снимка**, а не текущий список включённых модов.

После поиска передайте возвращённые `snapshotId` и raw-ID в `get_node`, `get_neighbors` или `describe_node`. `get_node.node` остаётся исходным захваченным узлом; краткая сводка располагается отдельно в `get_node.analysisFacts`. Полные захваченные `testFacts` содержат аннотации, метаданные Allure, fixtures, строки параметризованных данных и ссылки на ресурсы, если они были определены при построении карты. Соседство сохраняет типы связей `uses_test_data`, `has_attribute` и другие исходные отношения.

`describe_node` сочетает дерево текущего исходника с независимо помеченными данными снимка: `testFacts`, `codeProjectFacts`, `memberFacts`, `fieldFacts`, `dataFacts`. Их `sourceKind`/`sourceHash` не подменяют `sourceProvenance` текущего тела метода. Неподдержанные или динамические провайдеры остаются unresolved; объявленное число строк не означает число запусков, fixtures не доказывают порядок выполнения. `runtimeStatus: unknown` сохраняется.

Секции ограничены по числу элементов, длине текста и UTF-8 байтам. Удалённые подробности отмечаются явно. При превышении 64 КБ описание MCP сохраняет ограниченные сводки модов и направляет к точному узлу/соседству. Идентификаторы не обрезаются до выдуманных значений. Старые снимки без сведений о модах возвращают `analysisContext.status: unavailable`.

Контракт общий для всех языков: никакой Java/C#-ветки в MCP-проекции нет. Фактическая полнота зависит от реализованного анализатора и включённых при сборке модов. Добавление или изменение правил анализа требует обновить карту; улучшенные проекции MCP доступны сразу для уже захваченных фактов. Цветовые схемы и другие презентационные моды не добавляют анализ исходников.
