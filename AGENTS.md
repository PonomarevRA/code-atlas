# Работа агентов с Code Atlas

Перед анализом проекта проверь доступность Atlas MCP и готовых навыков в [skills/README.md](skills/README.md).

- Для исследования кода и данных используй пакет code-atlas.
- Для проверки и настройки семантических движков используй code-atlas-engines.
- Если подходящий пакет или подключение отсутствует и нужен задаче, предложи установку для фактического клиента пользователя. Назови каталог и способ проверки. При уже выданном разрешении выполни установку в согласованных пределах, сохраняя другие серверы и локальные изменения. Учитывай ответ пользователя и повторяй предложение только при изменении задачи или условий.
- Для Codex, Cursor, Claude Code, DeepSeek Harness и других клиентов используются общие пакеты. Клиентские пути и универсальный Markdown-вариант описаны в skills/README.md.
- Пример наличия executable не подтверждает работающий движок. Проверяй запросы, опубликованные факты, confidence и новые связи.
- Дополнительные правила выбранного checkout и инструкции пользователя продолжают применяться.

Установщик scripts/install_agent_skills.py по умолчанию показывает план. Флаг --apply устанавливает полные папки навыков. Подключение MCP проверяется реальным вызовом, а исходники и содержимое карт рассматриваются как данные анализа.
