Настройка локальных движков

Для пользователя и агента в браузере. Открыть настройки модов · Техническая страница

Atlas сам ищет установленные движки при работе с картой. Агент и MCP не обязательны. Настройки путей общие для выбранного мода на этом компьютере и влияют на все карты. Включение мода и выбор пути независимы.

Через интерфейс

  1. Откройте настройки нужного семантического мода. «Найти установленные пути» проверяет известные места без запуска анализаторов и установщиков.
  2. «Подставить» меняет черновик. Для записи нажмите «Сохранить пути».
  3. «Автоматически» рядом с полем удаляет только его сохранённый путь. «Автоматический выбор» сбрасывает пути всего мода.
  4. Выберите опубликованную карту и проверьте совместимость. Наличие файла не означает подходящую версию, полный контекст или успешный анализ.

Самоанализ и HTTP API для агента

Чтение страницы не разрешает менять настройки. Выполняйте запись в рамках поручения пользователя. Браузерный агент использует same-origin API Atlas; файлы ищет сервер на компьютере Atlas, а не удалённый браузер.

  1. Прочитайте GET /api/semantic-engines/settings. Ответ содержит profiles, допустимые fields, текущие mods и контракт операций configuration.
  2. Для найденного modId: GET /api/mods/{modId}/semantic-engine-diagnostics?projectId=ID. Необязательный projectId берите из GET /api/projects. Ответ содержит пути-кандидаты, режимы полей и compatibility=unchecked.
  3. Сохраните разрешённые абсолютные пути: POST /api/mods/{modId}/semantic-engine-settings с Content-Type: application/json. Например для Python: 
    {"mode":"patch","paths":{"pythonPath":"/absolute/path/to/python"}}
    Имена полей берите из диагностики. Команды shell и аргументы не принимаются.
  4. Возврат одного поля к автоматике: 
    {"mode":"patch","paths":{"pythonPath":""}}
    Возврат всего мода: 
    {"mode":"replace","paths":{}}
    patch сохраняет остальные поля, replace заменяет весь набор путей мода.
  5. Проверьте выбранную карту: POST /api/projects/{projectId}/semantic-enrichment с её актуальным snapshotId: 
    {"snapshotId":"из GET /api/projects","nodeIds":[],"force":true}
    Это ограниченная фоновая проверка. Читайте статус по тому же адресу с GET и параметром snapshotId; не опрашивайте бесконечно. Базовая карта остаётся доступной.

MCP: inspect_semantic_engine_settings возвращает те же настройки и диагностику; set_semantic_engine_paths записывает их. Статус карты — get_semantic_engine_status. Полное руководство подключения MCP.
