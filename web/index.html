03 / ДЕТАЛИ

Взгляд изнутри

Выберите узел на карте или в списке, чтобы увидеть путь к исходнику и связи.

Одна панель за раз: описание фактов, атрибуты, цепочка вызовов или исходник. Стрелки на карте — связи выбранного узла.

Снимок для агента

Сохранить выбранный узел и его окружение либо найти узлы по словам. Пояснения отделяются от фактов графа. Копия не меняется при перестроении репозитория.

Агент может создавать снимки и добавлять пояснения через stdio MCP Code Atlas. Запускайте команду из каталога установленного проекта:

.venv/bin/python -m atlas.cli --agent-mcp-config --port 8765

Ссылки работают локально, пока запущен сервер. Если ответ MCP обрезан, откройте тот же узел кнопкой «Описание». Снимок не публикуется в интернете.

Дополнительная документация · MCP

Отправляются только редактируемые ключевые слова, без исходного кода. Ответы инструмента показываются без генеративной модели.

Подключение MCP документации

Поддерживается Streamable HTTP через loopback; удалённые URL и stdio здесь не поддерживаются. Выберите инструмент только для поиска и чтения. Локальный MCP-сервер может обращаться в сеть согласно собственным настройкам; это подключение не гарантирует автономность сервера.

Сравнение Git

◯ Узлы изменённых файлов

Git checkout не изменяется. На карте подсвечиваются узлы изменённых файлов, не отдельные строки. Сравнение показывает, что сдвинулось между двумя ревизиями.
