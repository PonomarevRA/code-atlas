Моды и движок

Graphify извлекает код. Atlas дополняет факты. Моды меняют карточки, действия и группировки — без замены исходных связей.

Каталог модов

Положите папку с mod.json в этот каталог. Проектные файлы не подключаются как моды автоматически. Моды процессов добавляют локальный сбор фактов и документацию; после включения откройте процесс в его карточке.

Открыть карту без модов

JS и Python модов выполняют локальный код с правами приложения. Включайте доверенные моды. После изменения содержимого нужно явно включить новую версию.

Независимый Graphify

Можно выбрать отдельный Python-runtime с установленным graphifyy[mcp]. Его обновление не меняет Atlas, моды или существующие карты. Atlas ничего не скачивает при открытии страницы.

В новом окружении установите нужную версию, затем переключите путь. Старый runtime можно оставить для отката.

Диагностика движков для пользователя и агента

В настройках каждого семантического мода можно найти установленные пути, подставить найденный файл, сохранить выбор и вернуть отдельное поле или весь мод к автоматическому поиску. Настройки мода общие для всех карт на этом компьютере.

Агент в браузере может использовать эту страницу и её HTTP API без подключения MCP. Поиск подтверждает наличие файла; совместимость проверяется отдельно для выбранной карты.
