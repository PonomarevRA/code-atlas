Подключение MCP

Atlas должен быть запущен на том же компьютере, где работает MCP-процесс. Прокси подключается через stdio. Облачный агент не сможет обратиться к localhost вашего компьютера.

  1. Скачайте подходящий skill целой папкой. Для Cursor поместите её в .cursor/skills/, для Codex в проекте — в .agents/skills/.
  2. Добавьте запись сервера в настройки MCP, сохранив существующие серверы. Cursor использует .cursor/mcp.json; Codex — config.toml в каталоге настроек Codex.
  3. Включите или перезапустите MCP-сервер в клиенте. Запустите новый чат, затем попросите агента вызвать list_projects и проверить доступность Atlas.

Хранилище карт

Выбирайте карты явно. «Очистить снимки — оставить запись» сохраняет карты в списке для повторного построения. «Удалить выбранные карты» удаляет записи и их снимки. Кнопка строки «Удалить запись из списка» убирает только запись, оставляя физические файлы. Все три действия сохраняют исходники и авторские сохранённые виды. Размер строки включает все её данные; объём очистки рассчитывается отдельно.
