# Читаемые карточки: тема и группировки

Пакет `readable-cards`, версия `1.0.0`.

## Для чего

Показывает пример оформления карточки, метку MOD, действие исходника по двойному клику и три варианта группировки.

## Что объявлено

- Frontend: `mod.js`; doubleClick: `source`.
- Группировка `by-kind`; mode `field`, поле `kind`.
- Группировка `by-directory`; mode `directory`, глубина 2.
- Группировка `custom-python`; mode `python`; worker `grouping.py`, функция `group` по умолчанию.

## Пример проверки

На небольшой карте включите пакет, сравните by-kind и by-directory, проверьте открытие исходника двойным кликом. Затем отключите мод и сравните исходные ID и связи.

## Включение и обновление

Откройте «Моды и движок», изучите пакет и явно включите точный fingerprint. Чтение этой страницы не активирует код или рабочий процесс.

После изменения содержимого, включая wiki, перечитайте каталог: меняется общий fingerprint пакета. Исполняемую версию включают заново явно; изменение правил анализа требует нового снимка для новых фактов.

## Границы и диагностика

JS и Python выполняются с правами пользователя приложения. Python-группировка обязана вернуть каждый входной ID ровно один раз; она не должна менять факты или добавлять runtime-связи.

Если ожидаемые факты отсутствуют, проверьте точную версию и режим пакета, входные файлы, доступность нужного host-профиля и поля coverage/truncated/UNKNOWN. Отсутствие связи не доказывает отсутствие зависимости.
