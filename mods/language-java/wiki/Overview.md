# Java: структура проекта

Пакет `language-java`, версия `1.0.0`.

## Для чего

Выделяет исходные области проекта по точным расширениям, build-маркерам и правилам папок. Это декларативный профиль структуры, отдельный от Graphify и необязательного семантического движка.

## Что объявлено

- Язык `java`; правило `java-projects`.
- Расширения: `.java`.
- Имена build-маркеров: `pom.xml`; суффиксы: не заданы.
- Корни исходников: `src/main/java`, `src/test/java`; логические папки: разрешены.

## Пример проверки

Откройте Maven-папку с pom.xml и src/main/java/Service.java; проверьте области основного кода и тестов.

## Включение и обновление

Для декларативного анализатора доступен выбор по подходящим файлам при обновлении карты; явное «Выключено» приоритетно. Если пакет требует отдельного импорта документа или настройки движка, это остаётся отдельным действием.

После изменения содержимого, включая wiki, перечитайте каталог: меняется общий fingerprint пакета. Исполняемую версию включают заново явно; изменение правил анализа требует нового снимка для новых фактов.

## Границы и диагностика

pom.xml не запускает Maven. Тестовые аннотации и их данные требуют соответствующих framework-модов; структура проекта сама их не исполняет.

Если ожидаемые факты отсутствуют, проверьте точную версию и режим пакета, входные файлы, доступность нужного host-профиля и поля coverage/truncated/UNKNOWN. Отсутствие связи не доказывает отсутствие зависимости.
