# Документация по локальным фактам

Сначала включите `langgraph-guide`, затем этот мод. Процесс оформляет собранные исходники, комментарии и локальные справочники в проверяемый Markdown. Исходники и комментарии проекта не изменяются. LLM не подключена, смысловая корректность комментариев не проверяется.

Результаты неизменяемы и имеют снимок карты, ссылки и хэши источников. Проверка свежести доступна отдельно. Подробнее: `docs/mods-langgraph.md` в исходниках Atlas.
