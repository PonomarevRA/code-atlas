# Логи: профиль lnav

Пакет `logs-lnav`, версия `1.0.0`.

## Для чего

Объявляет статический профиль импорта документа через host-owned reader. Импорт выполняется явным запросом; содержимое файла не становится инструкцией для Atlas.

## Что объявлено

- Профиль `logs-lnav`; host-стратегия `logs-lnav-v1`.
- Входные расширения: `.log`.

## Пример проверки

Подготовьте небольшой .log и проверьте доступность нужного локального runtime перед явным импортом.

## Включение и обновление

Для этого профиля автоматический выбор выключен в manifest. Выберите режим явно и запускайте импорт по своей команде.

После изменения содержимого, включая wiki, перечитайте каталог: меняется общий fingerprint пакета. Исполняемую версию включают заново явно; изменение правил анализа требует нового снимка для новых фактов.

## Границы и диагностика

Заявление logs-lnav-v1 не доказывает наличие lnav в системе. Недоступный инструмент должен оставаться явным состоянием; чтение wiki его не устанавливает.

Если ожидаемые факты отсутствуют, проверьте точную версию и режим пакета, входные файлы, доступность нужного host-профиля и поля coverage/truncated/UNKNOWN. Отсутствие связи не доказывает отсутствие зависимости.
