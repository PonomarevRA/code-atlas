# Помощник по локальным фактам

Включите мод в каталоге Atlas, затем откройте процесс «Разобраться в проекте». Выберите проект, символ и границы обхода. Использует LangGraph и локальные SQLite checkpoints; LLM и сетевые вызовы не подключены.

Факты, комментарии, статические связи и справочные выдержки сопровождаются источниками. Это основа для будущих объяснений, а не смысловой ответ модели. Подробнее: `docs/mods-langgraph.md` в исходниках Atlas.
